The Setup Guide

1. Configure Repository

Fork the Pastime repo.

Generate a GitHub Personal Access Token (read:user, repo).

Save it as a Repository Secret named GH_TOKEN_FOR_GRAPH.

Ensure your repo's Actions settings allow Read and write permissions.

2. Run The Engine

Follow Steps 1, 2, and 3 below to design your theme.

Paste the YAML code into your forked .github/workflows/update-graph.yml.

Manually run the Action to generate your custom graph, then paste the Markdown image tag into your profile!
